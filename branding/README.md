# BioSphereAI logo set

Everything here is generated by `build.py` from one geometry source (the app's launcher icon).
To change the logo, edit `build.py` and run `python3 branding/build.py` from the repo root
(needs `fonttools` and ImageMagick 7 with librsvg). Don't hand-edit the exports.

| On light backgrounds | On dark backgrounds |
|---|---|
| ![](svg/logo-horizontal-on-light.svg) | ![](svg/logo-horizontal-on-dark.svg) |

## Which file to use

| Need | File |
|---|---|
| Website header, docs, slides | `svg/logo-horizontal-on-light.svg` / `-on-dark.svg` |
| Narrow spaces, title slides | `svg/logo-stacked-on-light.svg` / `-on-dark.svg` |
| App icon, avatar, anywhere the mark sits alone | `svg/icon-circle-dark.svg` (primary) or `-light.svg` |
| GitHub org/repo avatar | `png/icon-square-dark/512.png` (GitHub rounds it itself) |
| Rounded-square icon (docs, Slack, Discord) | `png/icon-rounded-dark/` or `-light/` |
| Just the mark, no badge | `svg/mark-on-light.svg` / `mark-on-dark.svg` |
| One colour only (print, stamps, embossing) | `svg/mono-mark-*.svg`, `svg/mono-badge-*.svg` |
| GitHub repo social preview (Settings > Social preview) | `social/github-social-preview-dark.png` (1280x640) |
| Link previews (`og:image`) | `social/og-image-dark.png` or `-light.png` (1200x630) |
| Website favicon | everything in `favicon/` (snippet below) |

"on-light" means the file is meant to sit on a light background (dark ink); "on-dark" is the reverse.
PNG folders contain sizes 16 to 1024 px (icons) or 256 to 2048 px wide (logos), all with transparent corners.

Icons at 32 px and below use an optical variant (thicker trace, larger dots, tighter crop) so the shape survives
at favicon size. Use the PNGs from `png/` at those sizes rather than scaling down the large SVG.

## Favicon snippet

```html
<link rel="icon" href="/favicon.ico" sizes="48x48">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">

```

## Colours

| | Dark | Light |
|---|---|---|
| Background | `#1C1D1F` graphite | `#F2F3F5` paper |
| Trace / wordmark | `#FFFFFF` / `#ECEDEE` | `#16181A` |
| Dots (accent) | `#7BC67E` | `#2F7D32` |

The two greens differ on purpose: the light green fails contrast on light backgrounds.

## Rules

- Keep clear space around the logo of at least the height of the larger dot times 2.
- Don't recolour the dots, stretch, rotate, outline, add shadows or gradients, or put the wordmark in another font.
- Wordmark is Manrope Bold (SIL Open Font License), converted to outlines, so no font install is needed.
